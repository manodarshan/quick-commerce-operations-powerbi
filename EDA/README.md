# Quick-Commerce Beginner EDA

This version is intentionally simple. It uses only one clean orders CSV and focuses on the Pandas concepts most likely to be discussed in a junior Data Analyst interview.

## Concepts used

- `pd.read_csv()`
- `.head()` and `.shape`
- `.isnull()` and `.duplicated()`
- Boolean filtering
- `.value_counts()`
- `.groupby()` and `.agg()`
- New calculated columns
- Sorting
- Basic Matplotlib charts
- Exporting analysis to CSV

## Run the script

```bash
pip install pandas matplotlib jupyter
python Quick_Commerce_Beginner_EDA.py
```

## Run the notebook

```bash
jupyter notebook
```

Then open `Quick_Commerce_Beginner_EDA.ipynb` and run the cells one by one.

## Disclaimer

The data is synthetic and is intended only for learning and portfolio use. It is not actual Flipkart internal data.
